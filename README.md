# ED4 Mobile native field milestone

사용자가 선택한 DOS 한글판 `ed4.zip`에서 원본 자료를 해석하는 Android 프로젝트입니다. 게임 자료는 저장소와 APK에 포함하지 않습니다.

현재 구현:
- 원본 AFLB 아카이브 / 연결 BZ 압축 블록 해제
- DATA_A 시작 마을의 128열 맵, 16×16 평면 타일 및 중첩 타일 복원
- DATA11 팔레트, DATA12 어빈 필드 스프라이트 8프레임
- 터치 목적지 이동 / 방향 전환 / 보행 프레임 / 카메라
- 1×·2×·3× 이동 속도, 위치 저장·불러오기, 뒤로가기 메뉴
- 삼성·만트라 원본 도입 화면

아직 전체 게임 플레이 버전은 아닙니다. 충돌/통행 속성, NPC/시나리오 이벤트, 맵 전환, 전투, 음악과 원작 세이브는 추가 해석이 필요합니다. 위치 저장은 이 앱의 필드 테스트 전용입니다.

`tools/ed4_assets.py GAME_DIRECTORY OUTPUT.png`로 원본 시작 마을을 독립적으로 검증할 수 있습니다.
